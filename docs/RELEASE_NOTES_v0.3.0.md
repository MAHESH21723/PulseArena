# Pulse Arena v0.3.0

A bright, stylized 4-player arena shooter for Android (landscape). Three-minute rounds, first to 15 eliminations. Play offline against bots or on the same Wi-Fi with friends.

## What is new

- **Visual overhaul:** a brighter, stylized arena with new lighting, models and effects.
- **New UI:** redesigned menus, HUD, settings and results, tuned for screens from 4:3 to 21:9.
- **New sound effects:** a freshly mastered set for weapons, hits, pickups, footsteps and menus.
- **Hit feedback:** hit markers, damage numbers, a kill feed, camera shake and optional vibration.
- **Aim assist:** mobile-friendly assist with an optional auto-fire. Adjust it in Settings.
- **Two weapons:** PX-24 Pulse Carbine and SX-8 Scatter Cannon.
- **Pickups:** shield and ammo pickups that respawn.
- **Smarter bots:** Easy, Normal and Hard; they use cover and hunt for pickups.
- **Same-Wi-Fi play:** host a room and friends on the same network join from the Nearby Rooms list or by room code.
- **Quality presets:** Battery, Balanced and Smooth.
- **Coming soon:** internet rooms through Epic Online Services (free, no servers).

## Install

1. Download `PulseArena-v0.3.0.apk` from the assets of this release on an Android 8.0+ ARM64 phone.
2. Open the file. When asked, allow your browser or file manager to **install unknown apps**.
3. Install and launch Pulse Arena. Turn the phone to landscape.

For Wi-Fi play, put both phones on the same network (a phone hotspot works). If rooms do not appear, the router may block device-to-device traffic ("client isolation"); turn it off or use a hotspot.

## Known issues

- Internet rooms are not available yet.
- The first launch can stutter briefly while shaders warm up.
- Testing so far was mostly on a PC and in the editor; physical-device coverage is limited, so please report problems.
- The host runs the match: if the host leaves, the room ends for everyone.
