# Pulse Arena

Android landscape first-person arena shooter. Original geometric sci-fi art, cyan / amber lighting, four-player private internet rooms, three-minute free-for-all matches, 15 eliminations to win. One player hosts the match; a departing host ends the room. Practice is available offline against three bots. No ads or purchases.

Menus: title, room host / join, room roster, settings, controls, pause / leave, HUD, scoreboard and results. Touch movement / look / fire / reload / sprint and desktop keyboard / mouse support. Synthesized original audio, procedural movement / recoil / reload animation, hit effects and respawn feedback.

Build deliverables: editable Unity 6.3 project, Windows test player, Android test APK where available, Play Store AAB build command, release setup guide. Public release requires the owner's final package identifier and signing key, successful device / internet-room tests, Play listing and policy declarations. No production signing credentials are embedded in the project.
