# Pulse Arena

Bright, stylized 4-player arena shooter for Android (landscape), built in Unity 6 (6000.6.2f1) with URP, Netcode for GameObjects, Input System, TextMeshPro and AI Navigation. Three-minute free-for-all rounds, first to 15 eliminations, two weapons, shield and ammo pickups, and Easy / Normal / Hard bots. No ads or purchases.

Modes: offline practice against three bots; same-Wi-Fi rooms (one phone hosts, up to four players, a departing host ends the room). Internet rooms through Epic Online Services (free, peer-to-peer) are planned and marked "coming soon"; Unity Relay and Multiplayer Services were removed.

Screens: title, room host / join, nearby rooms, roster, settings (volume, sensitivity, aim assist, auto-fire, haptics, HUD scale, bot level, quality), pause, HUD, scoreboard and results. Touch and desktop input.

Deliverables: the Unity project, an Android APK published on the GitHub release page, and a Play Store AAB build command. Public store release additionally needs the owner's signing key, physical-device and real-network testing, a store listing and policy declarations. No signing credentials are stored in the repository.
