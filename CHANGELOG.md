# Changelog

## v0.3.0 - 2026-11

- Visual overhaul: bright, stylized look with new arena art, lighting and effects.
- New UI: redesigned menus, HUD, settings and results; responsive from 4:3 to 21:9.
- New mastered sound bank and UI sounds.
- Hit feedback: hit markers, damage numbers, kill feed, camera shake, haptics.
- Mobile aim assist and optional auto-fire.
- Two weapons (PX-24 Pulse Carbine, SX-8 Scatter Cannon) and shield / ammo pickups.
- Smarter bots with Easy / Normal / Hard difficulty, cover and pickup seeking.
- Same-Wi-Fi rooms with nearby-room discovery.
- Quality presets: Battery, Balanced, Smooth.
- Unity Relay / Multiplayer Services removed; internet mode (Epic Online Services) is coming soon.
- Documentation rewritten; repository published on GitHub.

## v0.2.0

- Polish pass: weapons, bots, world, UI and audio, LAN play. Unity upgraded to 6000.6.2f1.

## v0.1.1

- Fixed an Android startup failure (stripped primitive colliders left the camera inside the reactor with no menu). `link.xml` now preserves them.

## v0.1.0

- Initial playable version: one arena, one weapon, private internet rooms, offline practice with bots.
